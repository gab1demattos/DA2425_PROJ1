Finds an alternative route different from the primary route.

Template Parameters
TNode ID type (typically int)
Parameters
gGraph object
primaryRouteThe primary route to avoid
sourceSource node ID
destinationDestination node ID
Returns
Pair containing:
  • vector of node IDs representing alternative path
  • total driving time (empty if no valid alternative)

Creates a modified graph by:

  1. Removing intermediate nodes of primary route
  2. Removing edges of primary route
  3. Finding best route on modified graph
Note
Returns empty vector if no valid alternative exists
Alternative must be longer than primary route
