Finds restricted route that must include specific node (if requested)

Template Parameters
TNode ID type (typically int)
Parameters
gGraph object
originSource node ID
destDestination node ID
avoidNodesVector of nodes to avoid
avoidSegmentsVector of segments to avoid
includeNodeNode that must be included in route (INT_MAX if not required)
[out]routeResulting path as vector of node IDs (empty if no valid route found)
[out]totalTimeTotal driving time in seconds (0 if no valid route)
[out]flagSuccess indicator (true if valid route found, false otherwise)

Finds shortest driving route from origin to destination while:

  1. Avoiding specified nodes and segments
  2. Including required node (if specified) by finding optimal path: origin → includeNode → destination
  3. Using Dijkstra's algorithm with driving times as edge weights
  4. Skipping walking-only routes

Handles edge cases:

  • Invalid/unreachable origin or destination nodes
  • Unreachable required node
  • No valid path exists meeting all constraints
  • Required node same as origin/destination

Core Dijkstra execution with restrictions (avoidNodes and avoidSegments)

Template Parameters
TNode ID type (typically int)
Parameters
gGraph object
startStarting vertex
avoidNodesVector of nodes to avoid
avoidSegmentsVector of segments (node pairs) to avoid

Runs Dijkstra's algorithm to find shortest paths while:

  1. Skipping nodes in avoidNodes list
  2. Skipping segments in avoidSegments list
  3. Using driving times as edge weights
  4. Skipping walking-only routes (where driving time is INT_MAX)
  5. Maintaining a priority queue for efficient vertex selection
  6. Relaxing edges to update shortest path distances
